EVP JS Submission Test

This page is designed to test how browser Email Verification Protocol (EVP) tokens are cached and handled during custom client-side JavaScript form submissions (AJAX/Fetch style where the page does not refresh).

How to test the Token Reuse issue:

  1. Verify you have set up a session for demo@rowan.fyi on your demo provider.
  2. Enter demo@rowan.fyi in the email field and click Submit (JS Processed).
  3. Notice that a token is successfully captured and printed in the logs below.
  4. Change the email field to an address that is NOT verified (e.g., nonexistent@rowan.fyi).
  5. Click Submit (JS Processed) again.
  6. Observe: If the browser or page fails to clear the hidden token input value, the submission will capture the exact same token from the previous submission, even though the email has changed and isn't verified!
Hidden Input Current Value: empty
Hidden Input Nonce Attribute: none
